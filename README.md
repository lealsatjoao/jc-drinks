# JC Drinks

Página de pedido de orçamento da JC Drinks (bar de drinks para eventos). O cliente escolhe a festa, a data, os drinks e o balcão e envia tudo pelo WhatsApp.

Site estático (GitHub Pages). O que muda (drinks, balcões, datas fechadas e número do WhatsApp) fica no começo do `app.js`.

Fotos: Unsplash (uso livre). Reflexo do vidro: HDRI "Studio Small 09" da Poly Haven (CC0). Logo redesenhado em vetor, dentro do `index.html`.
